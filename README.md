# Blazin-OS

A browser-based desktop operating system concept built with vanilla HTML, CSS, and JavaScript. No frameworks, no build steps — just open `index.html` in any modern browser.

## Features

- **Desktop Environment** — Icons, draggable windows, dock, and app launcher (Ctrl+Space)
- **Persistent Storage** — Files and notes saved to `localStorage`
- **Built-in Apps:**
  - 📝 **Notes** — Create, edit, and organize notes
  - 🧮 **Calculator** — Full-featured calculator
  - 📁 **Files** — Virtual filesystem with folders and text files
  - 💻 **Terminal** — Simulated shell with basic commands (`help`, `date`, `whoami`, `apps`, `echo`, `clear`)
  - 📅 **Calendar** — Simple date display
  - ⚙️ **Settings** — Accent color picker, reset filesystem
  - 🎵 **Blazin Music** — Built-in tracks + local audio file playback
  - 🎮 **Blazin Arena** — Twin-stick survival game (WASD + mouse)
  - ❓ **About** — Project info
- **Custom Background** — Drop `bg.jpg`, `bg.png`, `bg.webp`, or `bg.gif` in the folder to set your own wallpaper

## Quick Start

```bash
# Just open index.html in your browser
# Or serve locally:
npx serve .
# Then visit http://localhost:3000
```

## Custom Background

Place any of these files in the project root:
- `bg.jpg`
- `bg.png`
- `bg.jpeg`
- `bg.webp`
- `bg.gif`

The OS will automatically detect and use the first one found.
